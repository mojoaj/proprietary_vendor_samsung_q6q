# Proprietary vendor files for the Samsung Galaxy Z Fold6 (SM-F956B, q6q)

Generated by `extract-files.py` in [android_device_samsung_q6q](https://github.com/mojoaj/android_device_samsung_q6q)
from stock firmware F956BXXS2CYL5, with the secure-HAL and RIL groups taken from F956BXXS2BYGB.

The binaries are Samsung's and are provided only so the LineageOS build can be reproduced.
The makefiles and lists are maintained by Anthony Mckeever.
